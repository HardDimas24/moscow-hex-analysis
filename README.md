# 🏙️ Анализ привлекательности строительства в Москве (Hex-based)

## Описание проекта

Данный проект посвящён разработке сервиса аналитической оценки территорий Москвы с точки зрения **привлекательности нового строительства**.

В условиях высокой плотности застройки Москвы остаётся значительное количество территорий с нереализованным потенциалом:  
- устаревшая жилая застройка,
- промышленные зоны,
- слабо используемые участки городской ткани.

Цель проекта — **выявить такие территории и ранжировать их по градостроительной привлекательности**, опираясь на пространственные данные и инфраструктурные показатели.

---

## 🔷 Подход к анализу

В качестве базовой пространственной единицы анализа используется **гексагональная сетка (hex grid)** с шагом ~2 км.  
Гексагоны выбраны по следующим причинам:

- равномерное покрытие территории,
- отсутствие ориентационных искажений (в отличие от квадратов),
- удобство агрегации пространственных метрик,
- широкое применение в урбанистике и spatial analytics.

Каждая сота представляет собой независимую аналитическую единицу.

---

## 🏗️ Реновационный потенциал (Buildability)

Ключевая идея проекта — **строительство возможно только там, где есть потенциал для трансформации территории**.

В проекте вводится итоговая метрика:

### **Buildability Score**

Метрика отражает вероятность и целесообразность застройки территории и определяется как максимум из двух факторов:

1. **Жилищная реновация**

Для каждой соты берётся **доля площади**, занятую домами заданного периода (по умолчанию **1953–1972**):
```math
\text{housing\_raw}
=
\min\left(
\frac{\sum \mathrm{area}(\mathrm{house} \cap \mathrm{hex})}
{\mathrm{area}(\mathrm{hex})},
1
\right)
```
Полученное значение нормализуется логистической функцией
```math
\text{housing\_renovation\_score} =
\frac{1}{1 + e^{-k \cdot (housing\_raw - x_0)}}
```
2. **Промышленные зоны**

По аналогии с жильём:
```math
\text{promzone\_raw}
=
\min\left(
\frac{\sum \mathrm{area}(\mathrm{promzone} \cap \mathrm{hex})}
{\mathrm{area}(\mathrm{hex})},
1
\right)
```

```math
\text{promzone\_score} =
\frac{1}{1 + e^{-k \cdot (promzone\_raw - x_0)}}
```

Строительство возможно либо за счёт жилой реновации, либо за счёт промзон.
Поэтому итоговый потенциал определяется как максимум двух метрик:

```math
\text{buildability\_score} =
\max(
housing\_renovation\_score,
promzone\_score
)
```

## 🌆 Качество городской среды (Urban Quality)

Наличие территории под застройку — необходимое, но **недостаточное** условие.  
Важно, чтобы среда вокруг была комфортной для жизни и развития.

Для этого вводится отдельная метрика:

### **Urban Quality Score**

Она отражает инфраструктурную обеспеченность территории и рассчитывается как взвешенная сумма нормализованных показателей:

#### 🚇 **Доступность метро**
1.	Если хотя бы одна станция метро находится внутри соты, метрика принимает максимальное значение:

```math
metro\_score = 1
```

2.	В противном случае учитываются расстояния до станций:
```math
D = e^{-\frac{d_{min}}{500}}
```
```math
S = \min\left( \frac{1.0 \cdot n_{300} + 0.6 \cdot n_{500} + 0.3 \cdot n_{800}}{5},\ 1 \right)
```
```math
\text{metro\_score} = 0.7 \cdot D + 0.3 \cdot S
```
Где 
```math
d_{\min} \text{ - минимальное евклидово расстояние (в метрах) от гексагональной соты до ближайшей станции метро.}
```
```math
n_{x} \text{ - количество станций в радиусе x метров}
```

#### 🏫 **Обеспеченность школами**

Для каждой соты считается количество школ внутри неё, после чего применяется функция экспоненциального насыщения:

```math
\text{school\_score} = \frac{1 - e^{-\alpha \cdot c}}{1 - e^{-\alpha \cdot c_{max}}}
```
Где
```math
c \text{ - количество школ в соте,}
```
```math
c_{\max} \text{ - число школ, при котором метрика считается насыщенной (обычно 4),}
```
```math

\alpha \text{ - параметр крутизны роста}
```

#### 🌳 **Наличие зелёных зон и парков**

Метрика основана на доле площади соты, занятой зелёными зонами.

```math
p = \frac{\sum \text{area}(\text{park} \cap \text{hex})}{\text{area}(\text{hex})}
```

```math
\text{park\_score} =
\begin{cases}
0, & p < 0.05 \\
\frac{p - 0.05}{0.15}, & 0.05 \le p \le 0.20 \\
1 - \frac{p - 0.20}{0.20}, & 0.20 < p \le 0.40 \\
0, & p > 0.40
\end{cases}
```

### 🌆 Итоговая метрика качества среды
```math
\text{urban\_quality\_score} = 0.40 \cdot metro\_score
+ 0.30 \cdot school\_score
+ 0.30 \cdot park\_score
```

Все входные метрики приведены к диапазону [0, 1], что позволяет корректно их агрегировать.

### 🧮 Итоговый индекс привлекательности строительства

Финальная цель проекта — получить единый индекс, отражающий целесообразность строительства с учётом наличия территории и качества городской среды. Итоговая метрика определяется как произведение двух независимых компонент:

```math
\text{combined\_score} =
\text{buildability\_score}
\cdot
\text{urban\_quality\_score}
```
Если buildability_score = 0, строительство невозможно независимо от качества среды. Если urban_quality_score = 0, территория некомфортна для застройки.

Высокий итоговый балл получают только территории, где:
- есть потенциал трансформации,
- инфраструктура соответствует городским стандартам

## 🗺️ Визуализация и анализ результатов

Результаты расчётов визуализируются в виде интерактивной карты Москвы:
- каждая гексагональная сота окрашивается в соответствии с выбранной метрикой,
- предусмотрено переключение между между всеми метриками,
- центральный административный округ (ЦАО) может быть исключён из анализа как зона с особыми градостроительными ограничениями.

Дополнительно формируется рейтинг районов, основанный на лучших сотах:
- для каждого района выбираются TOP-N сот по combined_score,
- рассчитываются реднее значение, максимальный потенциал, число значимых сот.
